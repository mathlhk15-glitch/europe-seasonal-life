# 유럽 계절살이 — 혼자 살기와 부부가 함께 살기

한국을 생활의 본거지로 두고 유럽의 좋은 계절에 한 도시에서 한두 달 살아보는 방법을 정리한 공개용 정적 웹(GitHub Pages). `index.html`과 `assets/` 폴더를 함께 배포합니다.

## 구성
- 00 다시 펼칠 때(작성 시점 기준 변동 가능성과 먼저 확인할 것)
- 원칙, 두 방법 비교(혼자 살기 / 부부가 함께 살기), 동행 방식 A·B·C
- 도시 카드(사진·동네 후보·점검 항목), 계절별 대체 후보, 숨은 계절 리스크, 부부 생활 규칙
- 조건부 로드맵(준비 → 답사 → 혼자 생활 실험 → 부부 첫 체류 → 확장·축소·보류 → 매년 1월 재검토)
- 지도 이미지 5장 + 솅겐/비솅겐 개략 위치도 + 거점별 이동 시간
- 혼자/부부 예산 계산기(유로 환율·한국 고정비·물가상승 가정)
- 솅겐 90/180 계산기(나/배우자 분리, 3단계 판정, 날짜 추천)
- 숙소·생활권·의료 점검표, 7일 생활 실사, 비상 대응 순서
- 현지 평가(필수조건 → 가중 채점 → "다시 살고 싶은가?") 이력 저장
- 비자·제도 표(작성 당시 기준), 출국 준비 타임라인, 공식 자료 링크

## 개인정보·저장
- 본문에 실명, 학교, 개인 퇴직 시점, 가족 이름, 금융/의료 개인정보는 넣지 않음.
- 입력 기록은 브라우저 localStorage에만 저장되며 저장소로 올라가지 않음. JSON 백업/복원 지원. 이전 버전(v1)의 저장 데이터와 백업 파일도 자동으로 가져옴.
