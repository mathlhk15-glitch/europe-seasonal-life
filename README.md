# 유럽 계절살이 실전 로드맵

GitHub Pages에 업로드할 공개용 정적 웹. `index.html`과 `assets/` 폴더를 함께 업로드하세요.

- 본문에 실명, 학교, 개인 퇴직 시점, 가족 이름, 금융/의료 개인정보는 포함하지 않음.
- 솅겐 90/180일 참고 계산기, 예산 계산기, 도시별 비교와 평가, 체크리스트, JSON 백업/복원 지원.
- 수동 입력 기록은 브라우저 localStorage에만 저장하며 GitHub 저장소로 자동 업로드되지 않음.
- 지도 이미지 5장은 사용자가 제공한 원본 HTML에서 추출한 것. **기존 이미지의 저작권 및 공개 재배포 허가를 확인한 뒤 공개 배포하세요.** 권리가 불명확하면 지도 파일을 허가된 지도 이미지로 교체하세요.
- 공식 규정/물가/보험 조건은 여행 전에 다시 확인. 실제 예상 시세가 아닌 예시 숫자는 사용자가 직접 바꾸도록 설계됨.
